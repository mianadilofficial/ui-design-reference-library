# Security policy

## Supported versions

Only the latest release on the `main` branch is supported. Arc items are source code you copy into your project, so a fix reaches you when you update the affected files (for example by running `npx shadcn@latest add @uiarc/<id>` again).

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Use GitHub's private reporting: **Security**, then **Report a vulnerability**, on this repository.
- Or email **hello@uiarc.dev** with "Security" in the subject.

Include the affected item, the impact, and steps to reproduce. You will get a reply within a few days, and a fix or a plan within two weeks. Once a fix ships, you are credited in the changelog unless you prefer not to be.

## Scope

In scope: the source in this repository and the registry files it publishes (`registry.json`, `public/r/*.json`). The hosted site and its services are covered by the same address.
