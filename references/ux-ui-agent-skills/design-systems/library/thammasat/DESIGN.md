## Overview

Thammasat University (มหาวิทยาลัยธรรมศาสตร์) is a Thai public university, and the measured page is its English home, tu.ac.th/en/ (document title "Home - Thammasat University"). The page is an editorial university portal: a light header with the Thai and English wordmark and a text navigation (Home, About TU, Study At TU, Research, News, Contacts, a Thai/English switch, search and menu icons), a hero with the large red "THAMMASAT UNIVERSITY" wordmark and an arrow list (Education, Student, Staff, Alumni) over an orange sunset-style circle, then FEATURED STORIES, UPCOMING EVENTS with a "View All" button, COURSE (Undergraduate, Graduate, International, Online Course), a Thai/English mission statement, a video block, CAMPUS LIFE tiles, four campus address cards and a deep maroon footer.

The capture was first affected by a mourning notice overlay, a cookie consent dialog and a dark scrim; the tokens here were re-measured on the page and the overlay, cookie dialog and the translucent black scrim (#000000cc) are not documented as brand UI. The identity is crimson red (#c11b32) with gold (#fad157) on-button text, a very dark maroon (#48000a) footer, and neutral light grays. Photography is documentary: students, events and campus scenes, often with a warm red-orange color wash on tile images.

## Colors

The canvas is #f9fafb, with the page body at #f9f9f9 and the most extensive background area at #f1f2f3. Text is #63666a for body ink, #313235 for headings, navigation and card text, #45474a for links and #65707a for secondary labels. Light text on dark surfaces is #fefefe.

The primary color is crimson #c11b32, used as the "View All" button fill and border; the button text is gold #fad157. A darker red #a30a1a is measured for hover/pressed-type emphasis (its exact use was not isolated). The footer is #48000a, and a nearby darker maroon #5c000d is also present in the background area data. Category tiles in the Campus Life section carry per-tile fills that were measured as #67823a (olive green), #461e96 (purple), #f5c63a (yellow), #be4d00 (burnt orange) and #4298b5 (teal). Other measured surface colors are #d4d7da and #e5e7e9 (gray bands and borders) and #c3002f (a brighter red). The site's WordPress/Elementor-style global variables also define #101828, #475467, #98A2B3 (a slate gray scale) and a link color #444CE7 and gradient presets; those are page-builder defaults and are not used as brand colors here.

The site's own markup names the crimson "ci-red" (corporate identity red) in its utility classes, and the footer logo SVG fill is #C11B32, which equals the measured primary.

## Typography

Headings and navigation use Anantasorn Reno (loaded at 400, 600 and 700) with a system sans stack as fallback; section headings such as FEATURED STORIES use a face named Thammasat at weight 700; the page body uses Kanit (500 and 700) for Thai body text. Roboto 400 and icon fonts (Font Awesome 6, dashicons) are also loaded. The measured sizes: the story headline (h1 role) is 24px, weight 600, line height 36px, and 24px with a 32px line height at the 390px mobile pass; the section heading (h2 role) is 32px, weight 700, uppercase, line height 48px, and 24px with 36px at the mobile pass; body text is 17px weight 400 with a 21px line height; navigation links are 16px, weight 400, line height 24px; the "View All" button text is 21.008px, weight 600, line height 32px (18px with 24px at mobile); the large link role is 30px, weight 700, line height 36px. Headings are tracked out and uppercased, which gives the English headings a formal, institutional feel.

## Layout

The page is a stack of full-width bands inside a centred column. Featured stories pair one large photo with a headline and meta row (category chips such as FEATURED STORIES and PEOPLE & LIFE with a date) on the left and right, followed by a three-card carousel with chevron controls. The Course band places a photo beside four ruled link rows with red arrows. Campus Life uses a 3x2 grid of photo tiles with color overlays, and the Campus section uses four white address cards on a light gray band. The footer holds the logo, social icons, four columns of links and legal links. Spacing values include 2px, 4px, 6px, 7px, 8px, 10px, 12px, 14px, 15px and 16px; the navigation bar has 72px side padding.

## Elevation & Depth

Measured shadows: the navigation bar uses a Tailwind-style soft shadow (rgba(0, 0, 0, 0.1) 0px 4px 6px -1px, rgba(0, 0, 0, 0.1) 0px 2px 4px -2px); cards use rgba(0, 0, 0, 0.2) 0px 10px 30px 0px; another element uses rgba(0, 0, 0, 0.2) 0px 0px 6px 0px, and one uses a blue-gray rgba(73, 104, 126, 0.16) 0px 16px 24px 0px. Beyond those, depth is created by alternating light bands (#f9f9f9, #f1f2f3, white) and the dark maroon footer.

## Design System Architecture

The English identity pages (https://tu.ac.th/en/thammasat-identity/ and https://tu.ac.th/en/about/identity/) were opened; they present the university identity content but publish no token, color or type specification that could be cited, so no values were taken from them. The site is a WordPress build with Tailwind-style utility classes and a custom "ci-red" color name for the corporate red, and the root variables include page-builder (--eb-*) global color presets and --tw-* utilities. Page-builder gradient presets (lavender to light blue) are defaults and do not appear in the measured UI.

## Do's and Don'ts

- Do use crimson #c11b32 with gold #fad157 text for the main button.
- Do use uppercase, wide-tracked section headings in the Thammasat face.
- Do keep a calm gray canvas (#f9fafb, #f9f9f9, #f1f2f3) with photographs as the visual interest.
- Do use the deep maroon #48000a for the footer.
- Don't use the page builder's default blue (#444CE7) or lavender gradients.
- Don't document the mourning notice, cookie dialog, accessibility button or chat widget as brand UI.
- Don't use hard black scrims as a brand color.

## Responsive Behavior

Measured at the 390px mobile pass: the h1 is 24px with a 32px line height; the h2 is 24px with a 36px line height in a 234px box; body text is 17px with a 21px line height; the primary button text is 18px with a 24px line height in a 160px box. Breakpoints, menu behavior and column changes were not measured.

## Iteration Guide

1. Set canvas #f9fafb, ink #63666a, headings #313235 and accent #c11b32 with #fad157 text on buttons.
2. Use Anantasorn Reno for headings and Kanit for Thai body text; uppercase 32px section titles at weight 700.
3. Keep radii small (2px chips, 5px cards) with pill buttons.
4. Footer in #48000a.
5. Hover colors, dark mode and the mobile menu were not measured.
