# Mekha Cloud

Measured from https://mekha.cloud/ (final URL https://mekha.cloud/; title "Mekha Cloud — Cloud, Managed Service และ Cloud Migration"; `lang th`), 1280px desktop pass (page height 11,192px) and a 390px mobile pass. Mekha Cloud Company Limited (เมฆา คลาวด์) is a Bangkok cloud provider; the page's own JSON-LD lists its services: Cloud Compute and Scaling Groups, Cloud Container, Kubernetes as a Service, AI Agent, Storage and Data Protection, Network and Connectivity, Platform and Security Services, Cloud Observability, Managed Cloud Service, and Cloud Migration and Modernization.

## Overview

A bilingual-feeling Thai enterprise cloud page in a "liquid glass" style. A floating white pill header holds the logo (a cloud outline with the name "Mekha Cloud"), a nav (แพลตฟอร์ม, บริการ, ความปลอดภัย, ทำไมต้อง Mekha), a font-size control ("Aa"), a TH/EN switch, a sign-in link and a blue "เริ่มต้นใช้งาน" pill. The hero headline is "Cloud ที่ออกแบบมาเพื่อทุกทีม" (Cloud designed for every team) at 94.72px, with the second line "เพื่อทุกทีม" in blue; beneath are a short lead, two pill buttons ("เริ่มต้นกับ Mekha Cloud →" in blue, "สำรวจ Cloud Console ↗" in translucent white) and a chip row ("Bangkok Region", "เห็นค่าใช้จ่ายชัดเจน", "ความปลอดภัยสำหรับองค์กร"). Below sits a large dark panel with a data-center photograph and a frosted glass card ("โครงสร้างพื้นฐาน CLOUD: ทุกองค์ประกอบของ Cloud ทำงานร่วมกัน") with pill tags (Compute, Container, Kubernetes, Storage, Network, Managed Services, Migration). After a four-item proof strip (TH Bangkok Region, OPS, ISO), three white cards present DEV, OPS and SEC audiences.

The background is a page-wide set of soft radial glows (blue at the top left, violet at the top right, teal and blue lower down) over `#eaf1fb`. A dark cookie notice, "เว็บไซต์นี้ไม่ใช้คุกกี้เพื่อการวิเคราะห์..." with "อ่านนโยบาย" and "รับทราบ" buttons, overlays the hero in the capture; it is a consent control and is not documented as brand UI.

## Design System Architecture

No public Mekha Cloud design-system site or brand guideline was linked from https://mekha.cloud/. The shipped CSS is a tokenized de-facto system in :root: colors (`--blue`, `--blue-hover`, `--navy`, `--ink`, `--muted`, `--tertiary`, `--canvas`, `--surface`, `--surface-solid`), semantic tints (`--green`, `--green-soft`, `--purple`, `--orange`, `--cyan`), lines (`--line`, `--line-strong`, `--glass-border`), shadows (`--shadow`, `--shadow-float`), glass recipes (`--glass-fill`, `--glass-fill-strong`, `--glass-filter`), radii and `--content: 1180px`. It is custom CSS with no framework variables.

## Do's and Don'ts

- Do build on `#eaf1fb` with blurred, saturated glass panels, white 1px inner highlights and long soft shadows.
- Do use one blue gradient pill (`#0068d9` to `#0052ad`) per view for the main action.
- Do set the second line of the hero headline in blue.
- Do use full pill radii for buttons and chips and 24px for cards.
- Don't treat the dark cookie notice or its white "รับทราบ" button as brand UI.
- Don't use hard borders or flat drop shadows; glass edges are white highlights.
- Don't load an extra web font; the measured stack is the system stack.
