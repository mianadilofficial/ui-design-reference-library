# Drizzle ORM

## Overview

Drizzle ORM's page title is "Drizzle ORM - next gen TypeScript ORM." The home page at orm.drizzle.team is a white, informal, developer-humour page 8259px tall. A thin grey announcement line ("We've merged alternation-engine into Beta release. Try it out!") sits above a header with the slanted-stroke drizzle logo, a centred pill-outlined nav group (Get Started, Documentation, Studio, Benchmarks), a GitHub star count ("35k+"), a notification bell and a theme toggle.

The hero is a joke delivered with system fonts: "ORM for you to ~~settle~~" with "settle" scribbled out in blue and "ship ship ship" handwritten above it (the FirstTimeWriting font), "Backed by PlanetScale", JavaScript and TypeScript chips, and a 2×2 grid of grey tile buttons — Get Started, Documentation, Search Docs, Ask Docs. On the right, hand-drawn blue raindrop characters stand around a whiteboard showing a tiny pixel game with "Play" and "Normal" buttons.

The page continues with "We ship decently fast" (contributor avatars, a "v1.0 release 98%" progress bar and a month-by-month changelog in grey columns), "Performance — Drizzle doesn't slow you down" (Drizzle vs Prisma latency, requests-per-second and CPU charts with a dark "Go to benchmark results →" button), "Live on the edge" and "Connect to any database" (logo grids of runtimes and databases with small "new" badges and raindrop mascots), "Drizzle Studio — We never wanted to build a database browser" (tabs and a screenshot, "Explore Studio" and a dark "Live demo"), "Our Sponsors — Thanks to you, Drizzle team is rich", a mock "Pricing — Just kidding, Drizzle is free and open-source", a long wall of tweets "Developers love Drizzle ORM!", and a link-column footer ("Headless TypeScript ORM with a head").

## Typography

Drizzle loads no web text font: everything is the OS UI stack `ui-sans-serif, system-ui, -apple-system, "system-ui", "Segoe UI", Roboto, …`. The loaded fonts are only **Menlo** (400, for code) and **FirstTimeWriting** (the handwritten "ship ship ship").

- **display** — system sans 40px / 700 / 48px for the hero line (it is a div, not an h1; the extractor used the largest hero text). Mobile: 26px / 700 / 30px.
- **heading** — 32px / 600 / 48px for section h2s ("We ship decently fast"); 32px headings carry -0.64px tracking in places.
- **subheading** — 14px / 600 / 21px (h3s and tile-button labels).
- **body** — 14px / 400 / 21px.
- **link** — 12px / 500 / 17px. 12px is the dominant size on the page (36615 characters) because of the tweet wall and changelog.
- **button** — 16px / 700 / 16px for the dark buttons.
- **mono-label** — monospace 12px / 700 / 18px for the "v1.0 release 98%" progress label.

Small labels use positive tracking (14px / 0.7px, 10px / 1px, 16px / 1.28px). Menlo text was measured at 9.75px (798 characters).

## Design System Architecture

Drizzle does not publish a design system or brand guidelines (https://orm.drizzle.team/brand returns 404). The documentation website is open source at https://github.com/drizzle-team/drizzle-orm-docs ("Drizzle ORM documentation website"), with `src/ui`, `src/pages`, `src/assets` and MDX content folders. The measured CSS shows an Astro build (`--astro-code-*` syntax variables) with DocSearch (`--docsearch-*` variables, primary #5468ff) and a single `--default-font` system stack. There are no colour tokens as custom properties; the de-facto system is a small set of greys (#444444, #222222, #f6f6f7, #e8e8e8), one navy action colour (#282b3b), system fonts, and hand-drawn mascots that carry the personality.

## Do's and Don'ts

**Do**
- Keep the page white with grey #f6f6f7 tiles and #e8e8e8 hairlines.
- Use the system font stack; reserve handwriting for one joke per page.
- Use #282b3b for the few strong actions; tile buttons for navigation.
- Write with humour ("Thanks to you, Drizzle team is rich", "Just kidding").
- Use the blue raindrop mascots for illustration.
- Keep text small and dense (12–14px) in lists and changelogs.

**Don't**
- Don't introduce a brand accent colour for buttons; the system is greyscale plus navy.
- Don't round tile buttons; they are square.
- Don't add heavy shadows; use ring shadows on controls only.
- Don't load a custom text typeface.
- Don't use the DocSearch blue #5468ff as a brand colour.

## Responsive Behavior

Measured at 390px: the hero line is 26px / 700 / 30px (from 40px / 48px), the h2 20px / 600 / 30px (from 32px / 48px), and body stays 14px / 21px. The extractor's mobile primary CTA is "Go to benchmark results", unchanged at 16px 32px, 48px tall, 4px radius. No header links or menu toggle were detected at either width (desktop navigation sits in a pill group the extractor did not count). Content runs from x=20 or x=24 to x=366. Other behaviour was not measured.

## Iteration Guide

1. White canvas, #444444 text, #222222 headings, system-ui stack.
2. Navigation: #f6f6f7 square tiles with icons, hover #eff0f3.
3. Strong action: #282b3b, white 16px/700, 4px radius, 16px 32px, 48px.
4. Cards: #f6f6f7 or white with #e8e8e8 border, 8px radius, 8px padding.
5. Keep sizes small: 12px lists, 14px body, 32px section titles.
6. Add personality through copy and the raindrop mascots, not colour.
