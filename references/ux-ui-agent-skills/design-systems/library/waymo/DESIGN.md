## Design System Architecture

No public Waymo design system or brand guideline was linked from the home page; the link list covers product, safety, community and legal pages only. The page declares a single root variable (`--font-family-primary`) and otherwise uses compiled component styles; the stylesheet's color inventory is dominated by `#00e89d`, `#0077ff`, `#006fee`, `#5d6e83` and neutrals. The only media rule found in the HTML is `prefers-reduced-motion: no-preference`. Tokens in this file come from live measurement of https://waymo.com/.

## Do's and Don'ts

- Do set claims in large, tightly tracked GT-Walsheim and let photography show real streets.
- Do use `#006fee` pills for the one primary action on a band.
- Do alternate black cinematic bands with white product bands.
- Do round large media at 16px to 20px and use stadium shapes for hero crops.
- Don't use heavy weights; the page is almost all 400.
- Don't tokenize the app strip's black fill as a brand surface beyond what was measured.
- Don't use the red `#ea0000` from the stylesheet until measured on an element.

## Responsive Behavior

The mobile pass measured: h1 36px on 36px with −1.44px tracking (`display-mobile`), h2 45px on 45px, and the primary pill still 40px tall with a 40px radius. Other mobile layout changes are not measured, and the home page HTML declares no width-based media queries.

## Iteration Guide

1. Start with white, `#23233c`, `#050f1e` and `#006fee`; use `#0077ff` and `#00e89d` for statistics and gradient moments.
2. Use one weight and tighten tracking with size.
3. Photograph real places; avoid illustration.
4. Use circle-arrow links for secondary actions and a single blue pill for the main one.
5. Check any new radius against 3px, 16px, 20px, 40px and 50%.
