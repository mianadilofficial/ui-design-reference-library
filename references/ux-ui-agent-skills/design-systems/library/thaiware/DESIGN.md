## Overview

Thaiware (https://www.thaiware.com) is a Thai website for downloading software, with IT news, reviews, tips and online tools. The page title is "Thaiware.com | โปรแกรมฟรี ข่าวสาระไอที รอบหนัง เครื่องมือออนไลน์" (free programs, IT news, movie showtimes, online tools). The main menu lists หน้าแรก, ดาวน์โหลด, ข่าวไอที, รีวิว, ทิปส์ไอที, สินค้าไอที, เช็ครอบหนัง, รวมคลิป Thaiware and เครื่องมือ (tools such as internet speed check, IP check, parcel tracking, online random picker, number converter, mini-games and a date calculator). The page also promotes ThaiwareShop.com, which sells licensed software to organisations (Canva, AnyDesk, Antivirus.in.th, Minitab and an Adobe suite store).

The home page is a narrow, centred column on a pale blue-grey ground. A white logo card with the blue THAIWARE wordmark, round blue social icons (Facebook, YouTube, Twitter), a search field and a user icon opens the page; under it a rounded blue navigation bar carries bold white-on-blue labels with small separators; below, a dark-blue event banner, and a light strip with a movie-showtimes shortcut. The main content begins with a rounded blue title bar "ดาวน์โหลดโปรแกรม (Download Program)" and a light blue-outlined sub-bar "ดาวน์โหลดโปรแกรมใหม่" with the date (09-Oct-2026). Below this, software listings appear as a two-column grid of pale grey cards, each with a large square app icon at the left, the program name and version in blue, a two-to-three-line description in grey, platform icons (Windows, macOS, Linux, Android), a download count and a date in Thai Buddhist format. After "ดูเพิ่มเติม..." buttons come ranked lists ("โปรแกรมดาวน์โหลด สูงสุด ตลอดกาล", weekly) with large faint rank numerals and an orange-red "ยอดนิยม" badge.

The tone is informative and utilitarian, with Thai prose and English product names. The page measured 9,575px tall at 1280px wide.

Content cards stress practical metadata over marketing: every program entry shows the supported platforms, a running download count (for example 11,739,758 for the Internet Download Manager entry in the capture) and a posting date, so a reader can judge popularity at a glance. The sponsor carousel above the grid advertises software resellers in the same pale card style as the listings, which keeps commercial content visually consistent with editorial content.

## Design System Architecture

No public design system or brand guidelines were found; /about, /brand, /press and /design served the home page. The root CSS contains only the icon and carousel libraries' variables (`--fa-style-family-brands`, `--fa-font-solid: normal 900 1em/1 "Font Awesome 6 Free"`, `--swiper-theme-color: #007aff`, `--swiper-navigation-size: 44px`), so brand values are hard-coded in stylesheets. `#007aff` is Swiper's default theme color and is not a brand token. The type scale uses fractional pixel sizes.

## Do's and Don'ts

Do use `#0c78a6` for the navigation and title bars with white text, and `#005377` for buttons. Do keep body text at weight 300 in Kanit and Sarabun. Do round cards, bars and buttons at 8px. Do use pale teal and grey grounds to separate listings.

Don't use `#007aff` (Swiper default) or the consent popup's `#1387b9` as brand colors. Don't add large shadows. Don't present ads or the consent popup as UI components.
