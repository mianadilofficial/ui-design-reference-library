# Plausible Analytics

## Overview

Plausible (plausible.io) is a lightweight, privacy-friendly web analytics product. Its about page describes it as "an independent, open source analytics company based in the EU", "a team of 10", and AGPLv3-licensed. The marketing home page was measured at 1280px (6470px tall) and 390px. It is a calm, text-forward page in the platform's own system font. The design reads as a well-kept product page rather than a brand campaign.

From the top: a 104px header with the purple Plausible logo, a centered nav (Why Plausible, Resources, Pricing) and Login plus a "Start free trial" button on the right. The hero headline is centered, "Easy to use and privacy-friendly **Google Analytics alternative**", with the last phrase in indigo #5850ec. Below it come a two-line pitch ("No cookies, just insights. Made and hosted in the EU, powered by European-owned infrastructure"), a primary "Start free trial" and a white "View live demo" button, the note "30-day free trial · No credit card required", and a large screenshot of the real dashboard in a browser frame. The rest of the page is a four-column feature grid under "Why use Plausible Analytics?", a "People [U+2764 U+FE0F] Plausible" stats row (21k paying subscribers, 313B tracked pageviews, 99.99% uptime), six testimonial cards from named founders, a long-form letter "It's time to ditch Google Analytics" signed by the co-founders, a pricing section ("Traffic based plans that match your growth") with a pageview slider and four plan cards, a closing CTA, and a dark slate footer.

The microcopy is plainspoken and argumentative, with concrete numbers: the letter cites script size and CO2 savings. Imagery is product only. There are no illustrations or photography beyond small testimonial avatars.

- **Ink muted — #6b7280.** Nav labels, captions and secondary text (1833 characters). Nav links hover to #161e2e.

- **Ink on dark — #d2d6dc.** Footer text (722 characters).

## Typography

Plausible loads no web fonts (the loaded font list is empty). Everything renders in the platform system stack: `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif` plus emoji fonts. That makes the page feel native and keeps it fast, which fits the product's lightweight-script pitch.

Measured roles:

- **Display (h1)** — 48px / 48px, weight 800, -1.2px tracking, #161e2e with a #5850ec span.
- **Heading (h2)** — 30px / 36px, weight 800 ("Why use Plausible Analytics?").
- **Subheading (h3)** — 24px / 36px, weight 600 (letter section titles).
- **Body** — 18px / 32px, weight 400, #4b5563. The generous 32px line height suits the long-form letter.
- **Button** — 18px / 24px, weight 500 for the hero CTA. Smaller CTAs use 16px/500 and 14px/600.
- **Nav** — 16px / 24px, weight 400.
- **Link / card name** — 16px / 20px, weight 700.

Tracking is measured only on large sizes: -1.2px at 48px, -0.9px at 36px, -0.75px at 30px. The exception is 0.7px on 14px text (37 characters, the small uppercase labels). Size distribution by characters: 18px (2402), 16px (1799), 14px (1742), then 20px, 12px, 24px, 48px, 36px and 30px.

## Layout

The page is a single centered column on #f9fafb and white. The hero copy is centered and the h1 spans 1040px. The dashboard screenshot sits in a white browser-chrome frame with a large soft shadow. The feature grid uses 4 columns of icon-check items, the testimonial grid 3 columns, and the pricing grid 4 plan cards. The letter narrows to a single reading column of 736px for its paragraphs and headings. The footer is a two-part dark band: logo and tagline ("Made and hosted in the EU [U+1F1EA U+1F1FA]", "Funded entirely by our subscribers") on the left, four link columns (Why Plausible, Explore, Resources, Company) on the right.

Spacing is regular. The most frequent gap is 12px (36 uses), then 32px. The most frequent padding is 16px (34 uses), then 24px and 12px, with 64px and 96px used for section padding. Generated spacing tokens run 2, 4, 8, 10, 12, 16, 20, 24, 32 and 40px.

## Elevation & Depth

Three shadows were measured:
- `rgba(0, 0, 0, 0.1) 0px 1px 3px 0px, rgba(0, 0, 0, 0.06) 0px 1px 2px 0px` — the small default on cards and buttons (6 elements).
- `rgba(0, 0, 0, 0.1) 0px 4px 6px -1px, rgba(0, 0, 0, 0.06) 0px 2px 4px -1px` — a medium shadow on testimonial and plan cards (4 elements).
- `rgba(0, 0, 0, 0.25) 0px 25px 50px -12px` — the large shadow under the dashboard screenshot (1 element).

Focus rings are drawn as box shadows: a 3px ring at 45% opacity in blue tints (`rgba(118, 169, 250, 0.45) 0px 0px 0px 3px` on the primary CTA, `rgba(164, 202, 254, 0.45) 0px 0px 0px 3px` on "View live demo"), with a transparent 2px outline.

## Shapes

Corners are modest. 6px is the button radius (14 elements). 9999px pills (13) appear on the monthly/yearly toggle, the pageview slider and the small badges. 8px is used on testimonial cards, and 12px on plan cards and the dashboard frame (including `12px 12px 0 0` and `0 0 12px 12px` halves). There is one 3px and one 4px element. The visual language is softly rounded rectangles with hairline borders.

## Design System Architecture

There is no public Plausible design system or style guide. The about page at https://plausible.io/about mentions no brand kit, press kit, style guide or typeface; it only references the logo files `/assets/images/icon/plausible_logo.svg` and `/assets/images/icon/plausible_logo_dark.svg`. The de-facto system is visible in the shipped CSS: the page exposes a single root custom property (`--text-opacity: 1`) and no color or spacing variables, so the palette exists only as computed values. The neutrals (#f9fafb, #f4f5f7, #e5e7eb, #d2d6dc, #9fa6b2, #6b7280, #4b5563, #252f3f, #161e2e) are cool slate greys. The single brand hue is indigo #5850ec with its lighter step #6875f5, and the focus rings are blue tints. The product itself is open source under AGPLv3, per the about page.

## Do's and Don'ts

**Do**
- Use the system-ui font stack and load no web fonts. Weight 800 with negative tracking for headlines, 400 at 18px/32px for body.
- Keep backgrounds to #f9fafb, white and #f4f5f7, and keep text in the slate greys.
- Spend the indigo #5850ec sparingly: one headline phrase, the CTAs, stat numerals.
- Show the actual dashboard prominently, framed with the 25px/50px shadow.
- Write in plain, specific, numeric language, and let long-form copy run in a 736px column.
- Use 6px corners on buttons, 8px on cards and 12px on plan cards and frames.

**Don't**
- Don't add decorative illustration, gradients or stock photography; the page shows only the product and people's faces.
- Don't use cookie banners or popups; the product's message is that none are needed.
- Don't use multiple accent hues; indigo is the only brand color.
- Don't set the body in a display face or shrink the 32px reading line height.

## Responsive Behavior

Measured at 390px:

- h1 drops from 48px/48px (-1.2px) to **30px/40px** (-0.75px), weight 800. The indigo phrase stays.
- h2 stays **30px/36px**, weight 800.
- Body text drops from 18px/32px to **16px/28px**.
- The hero CTA is 16px/500 with padding `12px 32px`, keeping the #5850ec fill and the 6px radius.
- The nav keeps its 104px height with `32px 0px` padding. One header link was visible and no menu toggle was detected.
- Content is inset 16px on each side (16px to 374px) in the main bands, and 32px in the hero.
- Bands seen on mobile, in order: #f9fafb hero, a media band (the dashboard), white content, the #f4f5f7 pricing band, the #252f3f footer. Card grids measured at most 1 column.

Breakpoint values were not measured.

## Iteration Guide

1. Set `body` to #f9fafb with white content sections and the system-ui stack. Load no web fonts.
2. Build the type ramp: 48/48 at 800 with -1.2px, 30/36 at 800, 24/36 at 600, 18/32 body, 16/24 nav.
3. Create the #5850ec button with its three sizes (58px, 42px, 40px), the #6875f5 hover and the 3px translucent blue focus ring.
4. Frame the dashboard screenshot in a white 12px-radius frame with the large shadow.
5. Add the 4-column feature grid, the 3-column testimonial cards (8px radius, #f4f5f7 border), the 4-column pricing cards and the #252f3f footer.
6. Keep any new color inside the measured slate-and-indigo set.
