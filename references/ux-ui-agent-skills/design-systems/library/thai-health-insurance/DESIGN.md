## Do's and Don'ts

- Do use cyan #00aeef for the top bar, nav underline and section rules.
- Do use navy #123075 tiles with white text for product cards.
- Do set everything in Prompt: 40px/700 for display, 18px/500 subheads, 14px/400 body.
- Do keep uppercase 14px nav labels.
- Do not use the WordPress preset colours as brand colours.
- Do not treat the reCAPTCHA badge as UI.
- Do not mix in a second typeface.
- Do not round buttons beyond the measured 5px.

## Iteration Guide

1. Start from `canvas` white, `ink` #545454 and `primary` #00aeef.
2. Use `cta-blue` for the single filled button style.
3. Build feature rows from white cards and product rows from navy `card` tiles.
4. Keep Prompt and the 14px/25.2px body rhythm.
5. Lead with proof points in plain English: hospital counts, years in business, coverage plans.

Before changing any token, re-measure the live site with the repository extractor (`node web/scripts/extract-tokens.mjs --slug=thai-health-insurance --force`) and run `node web/scripts/verify-designs.mjs --slug=thai-health-insurance`; a value that is not in the measurement or in a cited source must not be introduced.
