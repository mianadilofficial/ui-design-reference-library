## Design System Architecture

No public design system, brand guidelines, logo download page or press kit is published: the home page (opened at https://www.cea.or.th/en/home) lists About, Creative Economy Review, Creative City Development, Projects, Our Services, Publications, Career, News, FAQ, complaint channels, E-Newsletter and privacy and terms pages, and none refers to brand guidelines or corporate identity assets. The footer logos are plain image links.

The de-facto system is a theme named in the logo path (`/themes/cea_2019/img/logo-cea.svg`). Its root exposes no color, type or spacing variables: only a set of easing curves (`--in-out-expo: cubic-bezier(1, 0, 0, 1)`, `--out-circ`, `--in-cubic-r` and similar) and cookie-consent variables (`--cc-*`), which belong to the consent dialog and are excluded. Brand decisions therefore live in the stylesheet values: `#ff5100` (136 uses in the CSS corpus), `#575756`, `#1d1d1b`, Poppins with Kanit, and a 1.25 modular size scale.

## Do's and Don'ts

**Do**
- Use CEA orange `#ff5100` for menu text, section headings, icon-button borders and the single filled button.
- Use `#575756` for text on white and `#1d1d1b` for dark feature sections with white titles.
- Set headings in Poppins 700 uppercase and keep nav and buttons uppercase with 0.8px tracking.
- Keep buttons and icon buttons square; give tabs 12px top corners only.
- Pair bright, graphic poster images with bold gray titles.

**Don't**
- Don't use the cookie-consent colors or easing variables as brand tokens.
- Don't round the primary button or the icon buttons; they measure 0px.
- Don't set Thai text in Poppins; the declared stack falls through to Kanit for Thai glyphs.
- Don't add gradients to buttons or shadows to cards; none were measured.
