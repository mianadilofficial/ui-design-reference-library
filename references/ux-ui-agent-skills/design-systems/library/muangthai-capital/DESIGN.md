## Overview

The measured page is https://muangthaicap.com/en/ (title "บริษัท เมืองไทย แคปปิตอล จำกัด (มหาชน)"), the English home page of Muangthai Capital, a consumer-lending company that presents loans, installment calculation and branch search. The capture shows a yellow utility strip (Investor Relations, Sustainability, Insurance Online, About us, Careers, Contact Us, a Thai-language link, TH and EN), a sky-blue header bar with the white logo and the menu Loan, บริการอื่นๆ, Installment Calculation, Branch Search and Application, a full-width photograph of a customer being handed a green document, and a blue promotional banner for installment loans on appliances and motorbikes with large yellow and white Thai headline lettering. "Customer Sharing" shows a 4.7 rating tile in solid blue with star bars next to white review cards, tagged with outlined product chips and a yellow "All Sharing" button. A headline "Muangthai Capital's Leader in Thailand's Microfinance" is followed by three counters (34 years, 8,906 branches, 4.7 customer review score) with blue line icons, and a pale blue branch-search panel with a text field, a blue "Branch Search" button and an outlined "search from your location" button. A promotional pop-up (scrim) and a green LINE chat button appeared in the first capture; the pop-up was hidden for measurement and neither is brand UI.

Measured facts about the capture: the page was loaded at a 1280px desktop viewport and its scroll height is 7559px; the document language is "en-US" and the document title is "บริษัท เมืองไทย แคปปิตอล จำกัด (มหาชน)". The extractor counted 1096 visible elements. Consent or overlay layers were hidden before measuring and are not documented as brand UI.

## Design System Architecture

No public design system, brand guideline or token package was found; the page was opened and links to none. The shipped theme exposes its own variable layer on the root: an --s-* set (--s-head-bg, --s-head-text:#ffffff, --s-head-height:50px, --s-color-hover, --s-text-1, --s-text-2, --s-bg-2, --s-radius, --s-rounded-2, --s-shadow-1, --s-heading-weight:400, --s-gap) alongside WordPress presets (--wp--preset--*), Kadence-style --global-kb-font-size-* clamp scales and --global-palette7/8. The --s-* layer is the de-facto token set.

The page declares 127 CSS custom properties on the root, for example `--s-gap: 16px`, `--wp-admin-theme-color-darker-20: #005a87`, `--wp--preset--font-size--large: 36px`, `--wp--preset--shadow--outlined: 6px 6px 0px -3px rgba(255, 255, 255, 1),`, `--wp--preset--color--vivid-purple: #9b51e0`, `--global-kb-font-size-xxl: clamp(2.5rem, 1.456rem + 3.26vw, 4rem)`, `--s-color-3: #47be9d`, `--s-color-hover: #0070c0`, `--global-kb-font-size-md: clamp(1.1rem, 0.995rem + 0.326vw, 1.25re`, `--wp--preset--color--pale-pink: #f78da7`, `--wp-block-synced-color--rgb: 122,0,223`, `--s-bg-2: #f5f5f7`, `--s-head-bg: #0098dc`, `--s-shadow-1: 0 0.5px 2px rgba(0, 0, 0, 0.16)`. 

## Do's and Don'ts

- Do use #0098dc for the navigation bar, buttons and key tiles, and #0070c0 for hover.
- Do use the yellow #fff03d for the utility strip and one secondary highlight button.
- Do set text in #4f4f4f with MuangthaicapText and headings in Muangthaicap Modern.
- Do use 5px radius on buttons and 20px on large panels.
- Do not use the promotional pop-up, LINE chat button or scrim as brand UI.
- Do not use the WordPress preset colours (for example #9b51e0) as brand colours.
- Do not use the yellow for large fills other than the top strip.
- Do not add shadows heavier than the 0 5px 20px nav shadow.

## Iteration Guide

1. Start from `canvas` white, `ink` #4f4f4f and `primary` #0098dc.
2. Use `accent-yellow` only for strips and secondary highlight buttons.
3. Build content tiles from `card` (solid blue) or white review cards.
4. Keep the two custom fonts and the 5px button radius.
5. Use counters with blue line icons for trust figures, as the page does.

Before changing any token, re-measure the live site with the repository extractor (`node web/scripts/extract-tokens.mjs --slug=muangthai-capital --force`) and run `node web/scripts/verify-designs.mjs --slug=muangthai-capital`; a value that is not in the measurement or in a cited source must not be introduced.
