## Do's and Don'ts

- Do use teal #01aa8d for primary actions and table headers and blue #0b5d99 for navigation.
- Do set text in Kanit with uppercase 15px/500 buttons.
- Do use red #ee3741 only for the single promotional headline accent.
- Do show loan terms in tables with a teal header row and thin grey borders.
- Do not use the cookie dialog or the grayscale tribute slide as brand UI.
- Do not use the CKEditor highlight colours as brand colours.
- Do not exceed the 4px radius on buttons.
- Do not use the Swiper blue #007aff as a brand colour.

2. Use blue `surface-3` for the navigation bar and `surface-2` for the backdrop band.
