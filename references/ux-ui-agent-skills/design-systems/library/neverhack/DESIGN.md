## Design System Architecture

No public NEVERHACK design-system or brand page was opened or searched for; the source is the shipped CSS of https://neverhack.com/. The page runs on Tailwind (`--tw-*` variables) with custom properties for the header height (`--header-h: 100px`) and motion curves (`--ease-out-cubic: cubic-bezier(.33, 1, .68, 1)`, `--ease-in-out-cubic: cubic-bezier(.645, .045, .355, 1)` and an ease-out-quint). Colors, type and shadows were taken from computed styles; Roobert is a commercial typeface and no foundry page was opened.

## Do's and Don'ts

Do:
- Set big headlines in Roobert 400 with strong negative tracking and keep them light.
- Use black pill buttons for the primary action and white ring pills for secondary actions.
- Use purple `#6b2bea` for small labels and links, red `#dc2626` only for critical status.
- Float cards with the faint navy-tinted shadows and a 0.5px inset ring.

Don't:
- Don't use Tailwind default blues except where measured (`#2563eb` on the Cyber AI link).
- Don't make headings bold; measured weights are 400 and 500.
- Don't use hard shadows or saturated fills for large surfaces.

## Responsive Behavior

On the mobile pass the h1 drops to 40px (43.2px line height, -1.2px tracking, 342px wide, 86px high) and the h2 to 36px (37.8px line height, -0.9px tracking). Other mobile values, breakpoints and nav collapse were not measured.

## Iteration Guide

1. Start from white and `#f6f7fc`, with `#4e4e4e` body and `#0a0f1f` headings.
2. Make actions black pills; secondary actions white pills with the inset ring.
3. Set type in Roobert with tracking that tightens as size grows.
4. Use purple for labels, and tinted chips for status tags.
5. Measure any new page before adding tokens: `node web/scripts/extract-tokens.mjs --slug=neverhack--<page> --url=<url> --force --no-motion`.
