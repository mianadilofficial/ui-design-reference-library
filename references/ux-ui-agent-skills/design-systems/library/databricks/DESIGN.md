## Design System Architecture

No public brand-guideline, media-resource or design-system link was found on the home page (read via WebFetch and curl); the closest pages are /company/newsroom and /product/open-source. The de-facto system is the shipped CSS at https://www.databricks.com/.

The root variables expose a small set: content widths (`--content-width-sm` to `-xxl`), Tailwind-style utility variables (`--tw-ring-color: rgba(59,130,246,.5)`, `--tw-ring-offset-color: #fff`, `--tw-shadow`), and `--swiper-theme-color: #007aff` for carousels. Brand colors and type are applied directly in rules rather than through root variables. Fonts are declared as DM Sans (400, 500, 600, 700), DM Mono (400) and an icon font. The page text includes the navigation mega-menus and an FAQ ("Get to know Databricks").

## Do's and Don'ts

**Do**
- Set headlines in DM Sans 500 in #1b3139 on light bands and white on #0b2026 bands.
- Use the square-cornered #eb1600 button for the main action and a dark #1b3139 button for the secondary one.
- Alternate white, warm (#eeede9), cream (#f9f7f4) and dark (#0b2026) bands.
- Introduce sections with an uppercase DM Mono eyebrow in orange.
- Give product screenshots the long layered shadow; keep buttons flat.

**Don't**
- Don't round the CTAs; the measured button radius is 0px.
- Don't use bold headline weights; the measured display weight is 500.
- Don't use stock Tailwind blue (#3b82f6, from `--tw-ring-color`) as a brand color.
