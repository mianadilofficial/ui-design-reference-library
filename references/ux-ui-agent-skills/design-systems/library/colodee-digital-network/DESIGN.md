## Overview

COLODEE DIGITAL NETWORK is a Thai infrastructure host (the page text names the company as "บริษัท โคโลดี ดิจิทัล เน็ตเวิร์ก จำกัด") selling co-location, dedicated servers, VPS plans and domain registration from a Bangkok data-center operation. The document language is Thai (`lang="th"`), the title is "COLODEE DIGITAL NETWORK — Co-Location, Dedicated Server, VPS", and the meta description promises a 100 Gbps fiber network watched around the clock.

The design reads as a network-operations console softened for customers. A thin top bar carries live-status copy in monospace ("ระบบออนไลน์ 24/7", the phone number 083-888-5445, "Line @colodee", support@colodee.com). Below it a white header holds the colored logo, the menu (หน้าแรก, Co-Location, Dedicated, VPS, Service, Payment, ร้านค้า, Contact) and a teal "Order" button. The hero is a dark navy field with a faint grid and a server photograph: the capture shows the slide "Dedicated Server Standard", a spec line "CPU Intel Xeon® E3-1241v3 3.50GHz (4 Core 8 Thread)", the price line "เริ่มต้น 4,000 ฿/เดือน" in teal, a solid teal "ดูรายละเอียด" (view details) button beside a bordered "ติดต่อเรา" (contact us) button, and a three-figure stat tile (100 Gbps fiber network, 99.9% uptime SLA, 24/7 NOC support). The hero is a carousel; another slide is headed "Co-Location Uplink Network Fiber 100 Gbps".

The sections that follow alternate dark and light: a domain-search band ("จดทะเบียนโดเมนของคุณวันนี้", register your domain today) with a white search field and a dark search button; a welcome statement on `#f5f7fb`; six white feature cards on "Why Colodee" (Domains, 24/7 Support, Network 100 Gbps, Firewall, Uptime 99%, KVM Over IP); dark product cards for Co-Location (฿1,500+) and Dedicated Server (฿2,000+); VPS plans from 500฿ to 1,200฿ per month; a free software-development offer; and a dark footer with the company address and contacts. The cookie-policy panel and the reCAPTCHA badge that appear over the hero in the capture are overlays, not brand UI, and are not documented here. The measured desktop page is 1280px wide and 5139px tall.

## Design System Architecture

No public design-system documentation or brand-guideline page is linked from the home page, so no official design system is documented. The site is a Next.js application (`/_next/static/chunks/0kqtfnmyd78od.css`) with Tailwind-style tokens compiled into root custom properties: spacing (`--spacing: .25rem`), containers (`--container-sm` to `--container-7xl`), radii (`--radius-md` to `--radius-3xl`), font weights (`--font-weight-normal`, `-medium`, `-semibold`, `-bold`, `-extrabold`), tracking (`--tracking-tight: -.025em`, `--tracking-wider: .05em`), default palette entries and a single custom color `--color-accent: #19e0cf`, plus the font variables above. The pages read are https://www.colodee.com/ and its stylesheet https://www.colodee.com/_next/static/chunks/0kqtfnmyd78od.css. Fonts are served through the framework's font loader with generated "Fallback" faces (`Chakra Petch Fallback`, `IBM Plex Sans Thai Fallback`, `IBM Plex Mono Fallback`) so that layout shift is controlled while the web fonts load.

## Do's and Don'ts

Do:
- Use teal `#19e0cf` only for the primary action and live-status accents, with a `#040a16` label.
- Alternate dark navy (`#07142b`) hero bands with light `#f5f7fb` and white sections.
- Set headlines in Chakra Petch 700, Thai and English running text in IBM Plex Sans Thai, and all small labels in IBM Plex Mono uppercase with 2.0736px tracking.
- Keep buttons at 8px radius and cards at 16px with a 1px hairline border.
- Show infrastructure facts as numbers (100 Gbps, 99.9%, 24/7) in compact stat tiles.

Don't:
- Don't put white text on the teal fill; the measured label is `#040a16`.
- Don't use the Tailwind default palette (slate, emerald, sky and so on) as brand colors.
- Don't add heavy neutral drop shadows; the measured depth is teal glow and thin translucent borders.
- Don't document the cookie panel, reCAPTCHA badge or glow circles as components.
- Don't use bold Thai headings below 700 in Chakra Petch; the measured headings are all 700.
