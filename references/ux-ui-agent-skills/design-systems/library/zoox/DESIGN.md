## Design System Architecture

No public brand guidelines, press kit, media kit or design system appear on the opened homepage; its one document link is "Supply Chain Standards". The de-facto system is a Next.js-style font setup (hashed font identifiers with generated fallbacks), a viewport-height variable `--vh`, and hard-coded colors. The typographic system has two roles by font cut (S for UI and labels, L for statements) and one tracking family of tiny negative values. Colors, radii and spacing are not exposed as named properties.

## Do's and Don'ts

- Do alternate `#d3e4df` and `#ffffff` fields with a single dark footer `#0b0e0e`.
- Do use mint `#64d5b3` with ink `#0d1212` labels for the main actions, uppercase at 12px and 700 weight.
- Do wrap media in large rounded frames (16px to 36px).
- Do set statements in the L cut at 28px and headlines at 56px, with slight negative tracking.
- Don't use shadows beyond the faint `rgba(23, 33, 30, 0.03)` under a card.
- Don't round the CTA buttons; they measured 0px.
- Don't treat the video pause button as a general button style.
