## Do's and Don'ts

- Do set big statements in Geist at weight 250 with negative tracking.
- Do keep body in Inter 400 at about 16px with -0.16px tracking.
- Do alternate white and duck-egg `#f1f5f8` sections with dark `#1b1b1b` sections.
- Do use dark blue `#3d5e86` for links and light blue `#d3e7ff` for the primary button fill.
- Don't use positive letter spacing.
- Don't introduce shadows; none were measured.
- Don't round beyond 3.56px except for explicit circles.

4. Add blue `#628ad1` only for borders and highlights.
