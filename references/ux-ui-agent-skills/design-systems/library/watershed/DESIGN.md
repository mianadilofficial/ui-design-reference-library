## Overview

Watershed's homepage (measured at `https://watershed.com/`, title "Watershed — The sustainability AI
platform") is a crisp, data-forward enterprise page. The capture shows: a dark navy announcement
strip ("New Research — See why Forrester named Watershed a leader…") above a white 68px header with
the globe-mark logo, four centred menu items (Platform, Solutions, Resources, Company), a pale
"Sign in" button and a Cobalt "Request a demo" button.

The hero is left-aligned: a tiny monospace data label ("■ 4.4Gt CO₂e Global EUM"), a 72px weight-500
headline "Where climate leaders are market leaders" with very tight tracking, a 20px slate subline,
and an email field fused to a Cobalt "Request a demo →" button. To the right and below, the hero turns
into a **collage of hard-edged colour blocks** — periwinkle, tangerine, forest green, deep navy —
interlocking with dithered, pixel-halftone mountain illustrations in pale cobalt, a product UI
fragment ("What are my strongest reduction levers?") on a navy panel, and a denim photograph. A
2×6 grid of customer logos (Anthropic, Wayfair, FedEx, Dell, Shopify, Walmart, Otis, Paramount, J&J,
BlackRock, Verizon, BMS) follows in hairline cells on pale cobalt `#f5f8ff`, then a customer story
with a cut-out portrait, a stat card ("15k↘ tons of CO₂, annually") and a serif quote.

The system is square, precise and quiet: 2px corners almost everywhere, 1px hairlines in
`#e6ebf5`/`#c0d0f0`, weight 500 as the default text weight, negative tracking on every size (−1% of
size for body, −3% to −4% for headlines, matching the site's `--tracking-headline: -.03em` and
`--tracking-display: -.04em`). Colour is concentrated in Cobalt `#265cff`; the warm brand colours
(Poppy, Marigold, Spring) appear in illustration blocks, not in UI chrome.

**Key characteristics**
- Cobalt `#265cff` for every primary action and link; hover `#1246e0`.
- Hero h1: messinaSans 72px / 500 / 72px line height / −2.88px.
- Most-read text colour is slate `#666c80`; headings `#242633`.
- 2px radius on buttons, inputs and cards; controls 40–47px tall.
- GeistMono 14px eyebrows in Cobalt ("More teams choose Watershed").
- P22 Mackinac (mackinacPro) serif for customer quotes.
- Large dark sections in navy `#041330` (second-largest background by area).

## Elevation & Depth

Watershed uses two depth vocabularies:
1. **Flat light UI** — hairlines and tints, almost no shadow. The hero form floats on a very soft
   cobalt glow (visible in the capture), and a stacked shadow
   `rgba(79,89,110,.02) 0 1.5px 1.5px … rgba(79,89,110,.14) 0 96px 96px` (seven layers, with an inset
   white top highlight) was measured on one elevated surface.
2. **Glass on dark** — on navy sections, cards are `#ffffff03` with inset edge lines:
   `rgba(255,255,255,.12) 0 1px 0 0 inset, rgba(255,255,255,.1) 1px 0 0 0 inset, rgba(255,255,255,.06) 0 0 0 1px`
   (4–5px radius). The CSS names this `--glass-light-edge` with `--glass-blur: 4px`.

Other measured shadows: `rgba(12,13,17,.15) 0 12px 24px 0` and `rgba(0,0,0,.05) 0 1px 0 0`.
Focus rings in CSS: `0 0 0 2px white, 0 0 0 3px var(--color-cobalt-core), 0 0 0 5px var(--color-cobalt-10)`.

## Design System Architecture

**Watershed publishes a brand page, not a public product design system.**
[watershed.com/brand](https://watershed.com/brand) ("Brand essentials") documents logo formats
(horizontal/vertical, dark/white), the nine-colour palette and the three typefaces with example
roles (H3 Messina Sans Book 48px, H5 P22 Mackinac 28px, eyebrow Messina Mono 16px). Searches found
no public component library, token package, Storybook or Figma community file.

**Token architecture (de-facto, from the live CSS).** The marketing site's `:root` exposes a clear
three-tier structure:
- *Primitives* — `--core-gray-10/20/30/100/white`, `--color-cobalt-5 … -100`, brand names
  `--color-poppy`, `--color-spring`, `--color-marigold`, alpha ladders `--alpha-dark-100 … -1200`
  (navy `#041330` at increasing alpha) and `--alpha-light-100 … -1200`.
- *Semantic* — `--color-text-primary`, `--color-text-secondary`, `--color-text-disabled`,
  `--color-background-light`, `--color-border-default`, `--color-border-light`, `--primary-color`,
  `--link-font-color`, aliased again as `--text-primary`, `--border-light`, `--background-light`.
- *Component* — `--primary-button-background-color`, `--secondary-button-text-color`,
  `--button-padding: 8px 16px`, `--form-radius`, `--form-padding-x/y`, `--form-focus-border`,
  `--form-error-ring`, `--toggle-active-color`, `--glass-light-edge`, `--nav-height`.
Naming is kebab-case `--{category}-{name}-{step}` with numeric steps for ramps.

**Theming.** No dark-mode switch was observed; light and dark are section treatments (white /
`#f5f8ff` vs navy `#041330`), with separate focus rings for each (`--color-cobalt-30` on dark).

**Type & spacing systems.** Type sizes are a named scale from `--font-size-2xs: 10px` to
`--font-size-12xl: 160px`; tracking is proportional (`-.01em`, `-.03em`, `-.04em`). Spacing is a
px-named scale (`--space-4` … `--space-240`) plus semantic section paddings (64/96/128px).

**Component model.** Not publicly documented. Observed: 2px-radius buttons in primary / secondary /
sign-in / outline variants, fused input+button, 40px nav items, glass and hairline cards, mono
eyebrows, toggle colours (`--toggle-active-color: #265cff`, `--toggle-inactive-color: #cbd5e0`).

**Accessibility.** No published rules. The CSS defines visible focus rings (2px white + 1px Cobalt +
2px Cobalt-10) and error rings for forms.

**Delivery.** The site is a Next.js build (`__messinaSans_da5535` is `next/font` output). Brand assets
(logos) are linked from the brand page. No versioned package is public.

## Do's and Don'ts

**Do**
- Use Cobalt `#265cff` for all primary actions and links; darken to `#1246e0` on hover.
- Keep corners at 2px; fuse input + button into one bar for capture forms.
- Set text at weight 500 with negative tracking (−1% body, −3/−4% display).
- Use GeistMono 14px eyebrows in Cobalt above section headings.
- Use mackinacPro serif only for customer quotes.
- Build hero art from flat brand-colour rectangles and dithered illustration, grid-snapped.
- Separate content with 1px `#e6ebf5`/`#c0d0f0` hairlines instead of shadows.

**Don't**
- Don't round buttons beyond 2px or use pills for primary actions.
- Don't use the warm brand colours (Poppy, Marigold) for text or buttons.
- Don't set body text in pure black; use `#666c80` with `#242633` headings.
- Don't use positive tracking.
- Don't add heavy drop shadows on light sections; use glass edges only on navy.

## Responsive Behavior

Measured at 390px:
- h1 72px → **40px/40px**, h2 35px → **28px/32.76px**.
- The hero CTA becomes full width (358px) at 13px/19.5px, `7px 24px 7px 11px` padding, 40px tall,
  2px radius.
- Body stays 20px/30px for the lead paragraph; the most frequent mobile sizes are 12px, 14px, 16px,
  20px and 13px.
- Header top padding shrinks (hero section `padding-top` 80px → 53px).
- Breakpoints from CSS: 480 / 768 / 1024 / 1200px.
